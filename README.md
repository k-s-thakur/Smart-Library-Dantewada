## 🚀 Key System Features
- **Book & Asset Tracking**: HF RFID (13.56 MHz, ISO 15693 / 28560) + Barcode/QR with anti-theft EAS gate alarms and handheld inventory wands.
- **Student & Staff Management**: Role-Based Access Control (RBAC), virtual dynamic QR/NFC ID cards, and tiered borrowing policies.
- **Automated Circulation**: Self-checkout multi-book RFID kiosks, 24/7 smart book return chutes, and automated fine calculation engines.
- **Smart Seat & Room Booking**: Live 2D floor maps with 15-minute auto-release check-in and IoT electronic door locks.
